# Sistema de Control de Stock - Ropa Masculina

Aplicación de escritorio desarrollada en Python para la gestión de inventario, talles, colores y stock de indumentaria masculina.

## Tecnologías utilizadas
* Python 3
* CustomTkinter (Interfaz Gráfica)
* SQLite (Base de datos local)
